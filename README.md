Backgammon Computación 2025

Autor
Nombre: Francisco Martín Gallardo

Descripción
Este proyecto implementa una versión básica del juego **Backgammon** en Python para la materia de Computación 2025, un juego de mesa clásico de estrategia para dos jugadores en el que cada uno debe mover sus fichas a lo largo del tablero y sacarlas antes que el oponente. La dinámica combina azar con decisiones tácticas, lo que lo convierte en un desafío entretenido y competitivo. El proyecto se está construyendo de forma incremental.
